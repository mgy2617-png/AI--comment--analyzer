文科生也可以做到的数据分析

一个面向非技术用户的 AI 文本分析工具。  
用户可以直接粘贴文本、上传表格或文档，让 AI 自动完成情感分析、批量分类、结果统计和文本关键词聚焦。本项目的目标是：让不懂代码、不懂 Prompt Engineering 的用户，也能完成基础的数据分析工作。
如果有想改进的请评论，此项目原型是博主自用完成论文工作的网站。可能会在功能上不够广泛，请多多的建议到这里来！

---

功能介绍

1. 单句分析

用户可以输入一段评论、评价、访谈内容或其他文本，系统会自动分析文本情感，并返回：

- 情感分类：Positive / Neutral / Negative
- 情感得分：0 到 1 之间的数值
- 简洁的分析结果

更适合快速查看单条文本的 AI 判断结果。


2. 批量分析

支持上传文件进行批量文本分析。

目前支持的文件格式包括：

- CSV
- Excel：`.xlsx` / `.xls`
- Word：`.docx`

批量分析完成后，系统会生成：

- 总评论数
- 正向评论数量
- 中性评论数量
- 负向评论数量
- 每条文本的分类和得分
- 可视化统计图表
- 评论明细表格

---

 3. 图表可视化

批量分析模式下支持自动生成统计图表。

支持的图表类型包括：

条形图
饼图
折线图


用户还可以自定义图表。



4. 结果导出

批量分析完成后，用户可以导出分析结果，方便后续整理和汇报。

支持导出：

- CSV 文件
- Excel 文件
- 图表 PNG 图片

---

 5.  / 词云分析

文本聚焦功能可以从上传的文本或文档中提取高频关键词，并生成词云图。

支持设置：

- 显示关键词数量
- 最小词长
- 最小词频

适合用于开放题答案、访谈文本、评论内容、问卷反馈等资料的初步整理。
